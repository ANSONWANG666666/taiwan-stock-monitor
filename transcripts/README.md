# 逐字稿收件匣

把新聞、節目或 Podcast 的逐字稿存成 `.txt`，上傳到這個資料夾：

1. GitHub 網頁進到 `transcripts/` → **Add file** → **Upload files**
2. 拖進 `.txt` 檔，檔名建議用「來源_日期」，例如 `財經節目_1016.txt`
3. 按 **Commit changes**

上傳後「觀察名單收錄過濾（Jev）」會自動執行，幾分鐘內 Telegram 收到結果：

- ✅ 有實質論點：講者提出具體的基本面理由，而且有可查證的事實（數字、產品、客戶）
- ❌ 排除：隨口提及、只說很強會漲、只有線型或目標價

不會自動加入觀察名單。想追蹤的話，在 `watchlist.yaml` 用自己的話寫下理由與**推翻條件**再加入。
