# 外部排程設定（cron-job.org）

GitHub Actions 的排程是「盡力而為」，忙碌時會延遲數小時或直接跳過。
這裡用免費的 [cron-job.org](https://cron-job.org) 準時呼叫 GitHub API 觸發執行，
GitHub 自己的排程只當備援。

## 1. 建立 GitHub token（只能觸發這個 repo 的 Actions）

1. GitHub 右上角頭像 → **Settings** → 左側最下面 **Developer settings**
2. **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
3. 填寫：
   - **Token name**：`cron-job-trigger`
   - **Expiration**：選 **Custom**，設一年後（到期前記得換新的）
   - **Repository access**：**Only select repositories** → 選 `taiwan-stock-monitor`
   - **Permissions** → **Repository permissions** → **Actions**：**Read and write**
     （其他都不用開；Metadata 會自動變成 Read-only）
4. 按 **Generate token**，複製 `github_pat_...` 開頭的字串（只會顯示一次）

這個 token 只能觸發與查看這個 repo 的 Actions，不能改程式碼、不能讀其他 repo。
外洩時到同一頁按 **Delete** 即可立即失效。

## 2. 在 cron-job.org 建立排程

註冊並登入 cron-job.org 後：

1. 右上角帳號 → **Settings** → **Timezone** 設為 `Asia/Taipei`
2. **Cronjobs** → **Create cronjob**，依下表建立 3 個：

| Title | URL | 時間 |
|---|---|---|
| 台股盤中監控 | `https://api.github.com/repos/ANSONWANG666666/taiwan-stock-monitor/actions/workflows/intraday.yml/dispatches` | 週一～五 08:50 |
| 台股全市場掃描 | `https://api.github.com/repos/ANSONWANG666666/taiwan-stock-monitor/actions/workflows/market_scan.yml/dispatches` | 週一～五 15:10 |
| 台股成效週報 | `https://api.github.com/repos/ANSONWANG666666/taiwan-stock-monitor/actions/workflows/weekly_report.yml/dispatches` | 週五 17:10 |

時間設定：**Execution schedule** 選 **Custom**，勾選對應的星期、填小時與分鐘。

3. 每個 cronjob 都切到 **Advanced** 分頁設定：
   - **Request method**：`POST`
   - **Headers**（按 Add 逐一加入）：

     | Key | Value |
     |---|---|
     | `Accept` | `application/vnd.github+json` |
     | `Authorization` | `Bearer github_pat_你的token` |
     | `X-GitHub-Api-Version` | `2022-11-28` |
     | `Content-Type` | `application/json` |

   - **Request body**：`{"ref":"main"}`

4. 按 **Create**，再按該 cronjob 的 **Test run**：
   - 回應 **204 No Content** = 成功
   - 到 GitHub 的 **Actions** 頁面，應該看到一筆新的執行，觸發方式是 `workflow_dispatch`
   - 401／403 = token 錯或權限沒開 Actions: Read and write
   - 404 = URL 打錯（注意 `.yml` 檔名）
   - 422 = body 不是 `{"ref":"main"}`

> 測試「台股盤中監控」時，如果在非交易時間按 Test run，它會看到已過 14:10 或是週末，
> 幾秒內就自己結束，這是正常的。

## 重複觸發會不會重複推播？

不會。cron-job.org 與 GitHub 備援排程可能都會觸發，但：
- 盤中監控：同時只會有一個在跑，後到的排隊；輪到它時已過收盤就直接結束
- 全市場掃描、週報：同一天已推播過就自動跳過
