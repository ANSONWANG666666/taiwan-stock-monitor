# 觀察名單：價格異常與回檔提醒

型態選股是「程式找標的」；觀察名單是「你研究過、想追蹤的股票」。
你寫下**核心投資理由**和**推翻條件**，系統每天收盤後檢查，觸發時推播提醒並附上：

- 你當初寫的理由與推翻條件
- Jev 新聞查證
- 當下的市場溫度

提醒只代表「該去檢視」，不是買賣訊號。

## 不用新增任何排程

全部掛在現有的工作流程上，cron-job.org 不用改：

| 時間 | 掛在哪個工作流程 | 做什麼 |
|---|---|---|
| 週一～五 08:50 | 台股盤中監控 | ☀️ 開盤前市場溫度卡（09:30 前、交易日、一天一次） |
| 週一～五 15:10 | 台股全市場掃描 | 觀察名單提醒＋Jev 新聞查證；📉 大型股回檔摘要；計算市場溫度存到 data 分支 |
| 週五 17:10 | 台股成效週報 | 📬 觀察名單每週覆盤（另一則訊息）；週報多一段「觀察名單提醒（提醒後表現）」 |
| 上傳逐字稿時 | 觀察名單收錄過濾（Jev） | 判斷講者有沒有實質論點，看多的自動加入名單 |
| 手動 | 觀察名單門檻回測 | 10 年回測，決定提醒門檻 |

## 第一次使用

1. **加入觀察標的**：在 GitHub 網頁編輯 `watchlist.yaml`。檔案最下面有範例，刪掉每行開頭的 `# ` 就會生效，理由請換成你自己的。
2. **跑一次門檻回測**：Actions → **觀察名單門檻回測** → Run workflow（股票代號留空 = 名單全部）。
   - 看摘要頁的「建議提醒數值」。
   - 需要的話調整 `watchlist.yaml` 的 `settings.ladder`。
3. **選填**：到 Settings → Secrets 新增 `FINMIND_TOKEN`。不填也能用，只是「外資連續賣超」的推翻條件查詢次數比較少。

`TYPESAFE_API_KEY`、`TELEGRAM_*` 沿用原本的設定。

## 提醒規則

| 等級 | 條件（以 2330 的波動度為基準） | 意思 |
|---|---|---|
| 🟡 第一級 | 自 20 日高點回檔 5% | 日常關注 |
| 🟠 第二級 | 自 20 日高點回檔 10% | 深度檢視 |
| 🔴 第三級 | 自一年高點回檔 20%，或收盤剛跌破 200 日均線 | 重大回檔警報 |
| 🔔 其他 | 正乖離 200MA 過熱、爆量 2 倍、布林寬度一年最低 5% | |
| ⛔ 推翻條件 | `rules` 裡的條件成立 | |

- **門檻依波動度調整**：每檔的門檻會乘上「該股波動 ÷ 2330 波動」，倍數限制在 0.7～2.5。例如波動是台積電 2 倍的股票，第二級門檻是 20%。
- **防噪**：同一檔、同一類提醒 72 小時內不重發；等級升高（第一級變第二級）會立即通知。
- **Jev 新聞查證**：預設只有第二級、第三級、爆量、推翻條件會查。用的是全市場掃描那個工作流程原本的每日額度（100 次），因為全市場掃描已經不查新聞。
- **週報統計**：每則提醒都會寫進訊號紀錄簿（journal 分支 `signals_watch.csv`），自動回填 5／20 日超額報酬。週報會統計每個等級之後的實際表現，用來檢查門檻有沒有意義。

## 加碼閘門（固定公式，100 分 = 有利加碼）

| 指標 | 計分 | 資料來源 |
|---|---|---|
| 上市櫃站上 200MA 比例 | 100 − 比例 | data 分支全市場 |
| 加權指數 200MA 乖離 | 50 − 2 × 乖離%（0～100） | data 分支 |
| 櫃買指數 200MA 乖離 | 同上 | yfinance |
| VIX 一年分位 | 分位 | yfinance |
| 美國高收益債利差一年分位 | 分位（`risk_off` 時反向） | FRED |
| 美 10 年債殖利率一年分位 | 100 − 分位 | yfinance |

六項平均：≥70 按計畫加碼、40～70 減量、<40 暫停加碼。某項抓不到資料就不計入平均，卡片上顯示「—」。

## 名單怎麼來：三種方式

不直接對全市場發回檔提醒：同一套規則套到全市場，每天會有約 600 則（已計入冷卻）。
所以「找標的」和「盯標的」分開處理：

1. **自己寫**：在 `watchlist.yaml` 寫下理由與推翻條件。
2. **Jev 自動收錄**：逐字稿上傳到 `transcripts/`，講者有實質論點而且看多的股票會自動加入，標記 `auto: true`。
   - 理由暫用講者原文，推翻條件暫用「跌破 200 日均線」。
   - 改成自己的之後，刪掉 `auto: true`；不想追蹤就整段刪除。
   - 每份逐字稿最多加入 5 檔。看空、中性、只用關鍵字判斷（沒有 Jev 金鑰時）的不會自動加入。
3. **大型股回檔摘要**：每天收盤後，從流動性前 150 大中，挑出「今天新進入」第三級的股票，合併成一則訊息。
   - 第三級是指自一年高點回檔達門檻，或剛跌破 200MA；門檻同樣依波動度校正。
   - 用近 60 個交易日回推，平均每天約 3 檔，沒有就不推。
   - 這只是發現標的，想追蹤再加進名單。週報會統計這些股票之後的表現。

## 逐字稿收錄過濾（Jev）

把逐字稿 `.txt` 上傳到 `transcripts/`，Jev 會對每檔被提到的股票回答三個問題：

1. 講者有沒有提出具體的基本面理由
2. 有沒有可查證的事實
3. 看多還是看空

前兩題分數夠高才列為候選，其中看多的會自動寫進 `watchlist.yaml`，結果推到 Telegram。說明見 `transcripts/README.md`。

## 每週覆盤（週五）

1. 今年以來報酬：組合 vs 0050。如果落後，會直接寫「選股目前沒有帶來超額報酬」。
2. 本週提醒，以及提醒之後的走勢。
3. 推翻條件：
   - 程式能判斷的，直接列出是否觸發。
   - 文字條件逐條問你本週是否發生。
4. 市場溫度。

有加減碼請更新 `holding.shares`，否則報酬計算會失真。
